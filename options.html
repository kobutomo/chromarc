Chromarc の設定

タブの自動アーカイブ
使わなかったら閉じる

表示中のタブ、Chrome でピン留めしたタブ、音声再生中のタブ、ブックマークから開いたタブは閉じません。 閉じたタブはサイドバー下部の「アーカイブ済み」から復元できます。

選んだフォルダの中身がサイドバー上部に表示されます。

GitHub のレビュー依頼

トークンが空の場合は、ブラウザでログイン中の GitHub のページ(github.com/pulls/reviews と github.com/pulls/assigned)を取得して一覧を作ります。 うまく取得できない場合は、repo の読み取り権限を持つトークンを入れると GitHub API で取得します。 トークンはこのブラウザの拡張機能ストレージに平文で保存されます。
