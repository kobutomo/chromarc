# Chromarc

Arc ブラウザのサイドバーを Chrome で再現する拡張機能です。Chrome のサイドパネルに、ブックマークとタブを一覧表示します。

## 主な機能

- ブックマークをピン留めタブのように表示(タイル表示、フォルダ、ドラッグでの並べ替え)
- タブ名の変更(名前なしも可)
- 非アクティブなタブの自動アーカイブと、アーカイブからの復元
- 表示中のタブ以外をまとめて閉じる「クリア」
- 分割ビューの 1 行表示、ドラッグでの分割、分割ビューごとのブックマーク登録
- Google Meet のタブを「Current Meeting」にまとめて表示
- サイドバーの文字サイズ変更

## 動作環境

- Google Chrome 121 以降
- 分割ビュー関連の機能は Chrome 155 以降

## インストール手順

Chrome ウェブストアには公開していないため、ソースコードを直接読み込みます。ビルドは不要です。

1. リポジトリを取得します。

   ```sh
   git clone git@github.com:kobutomo/chromarc.git
   ```

2. Chrome で `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、取得した `chromarc` フォルダを選びます。
5. ツールバーの拡張機能アイコン(パズルのピース)から Chromarc をピン留めし、アイコンを押すとサイドバーが開きます。

## 初期設定

- **サイドバーを左側に出す**: `chrome://settings/appearance` の「サイドパネルの位置」で「左側に表示」を選びます。Chrome 全体の設定なので、他のサイドパネルも左側に出ます。
- **ショートカットで開く**: `chrome://extensions/shortcuts` で、Chromarc の「拡張機能を有効にする」にキーを割り当てます(既定の候補は `Alt+S`)。
- **自動アーカイブの時間・文字サイズ・表示するブックマークフォルダ**: サイドバー下部の「設定」から変更します。

## 更新手順

1. `git pull` で最新のコードを取得します。
2. `chrome://extensions` で Chromarc の更新ボタン(↻)を押します。
3. サイドバーを開き直します。

## アンインストール

`chrome://extensions` で Chromarc の「削除」を押します。Chrome のブックマーク自体は残りますが、拡張機能側に保存している情報(タブ名、アーカイブ、分割ビューの相方の URL、フォルダの色など)は消えます。
